# আমার বাংলা — ফটোকার্ড মেকার

ব্রাউজারে চলে, কোনো সার্ভার লাগে না। ছবি কোথাও আপলোড হয় না, সব কাজ আপনার নিজের ব্রাউজারে হয়।

## যা যা করা যায়
- ৬টা ডিজাইন: বৃত্ত, পুরো ছবি, ফ্রেম, ব্রেকিং, উক্তি, দুই ছবি (বনাম)
- ৪টা মাপ: ফিড ৪:৫, বর্গ ১:১, স্টোরি ৯:১৬, চওড়া ১৬:৯
- শিরোনামে *তারকা* দিয়ে শব্দ লাল বাক্সে দেখানো (বা শুধু রঙে), লেখার আকার, মাঝে বা বাঁয়ে বসানো
- বিভাগ, বাংলা তারিখ (চাইলে বঙ্গাব্দসহ), ছবির সূত্র
- ছবি: বেছে নেওয়া, টেনে এনে ছাড়া বা Ctrl+V দিয়ে পেস্ট; টেনে সরানো, জুম (মাউসের চাকাতেও), উজ্জ্বলতা, কনট্রাস্ট, সাদাকালো
- ৬টা রঙের থিম + নিজের পছন্দের রং
- PNG, JPG ডাউনলোড, অথবা সরাসরি কপি করে ফেসবুকে পেস্ট; Ctrl+S চাপলেও ডাউনলোড
- শেষ ব্যবহার করা ডিজাইন ও সেটিংস মনে রাখে
- লিংক দিয়ে আগে থেকে লেখা বসানো যায়:
  `https://আপনার-সাইট.vercel.app/?title=শিরোনাম&cat=জাতীয়&sub=ছোট লাইন`

## GitHub-এ আপলোড
1. github.com → **New repository** → নাম `amarbangla-photocard` → **Create repository**
2. **uploading an existing file** লিংকে চাপুন
3. এই ফোল্ডারের **সব ফাইল ও ফোল্ডার** (index.html, app.js, style.css, vercel.json, assets, fonts) টেনে এনে ছাড়ুন
4. নিচে **Commit changes**

## Vercel-এ চালু (ডিপ্লয়)
1. vercel.com → GitHub দিয়ে লগইন → **Add New → Project**
2. `amarbangla-photocard` রিপোর পাশে **Import**
3. Framework Preset: **Other**; কিছু বদলাতে হবে না → **Deploy**
4. এক মিনিটে লিংক পাবেন, যেমন `amarbangla-photocard.vercel.app`

পরে GitHub-এ কোনো ফাইল বদলালে Vercel নিজে থেকে নতুন সংস্করণ চালু করে দেবে।
